a.1. basicamente o DNS ele vai traduzir o domínio do site, sua URL para um IP próprio e assim esse IP será enviado para o servidor
a.2. o HTTP basicamente vai enviar o IP traduzido pelo DNS para o servidor e esse servidor vai enviar todos os arquivos e informações necessárias para que o site apareã para o cliente

O método GET ele busca informações, como o próprio nome já diz, nesse método é possível ver na URL as informações
O método POST envia informações, não aparecendo na URL as informações enviadas, aumentando o nível de segurança

**Técnica 1 -- Nome:** Diminuição do tamanho dos arquivos como vídeos, gifs, imagens que estão no site.
**Técnica 2 -- Nome:** Utilizando melhores servidores, evitando quedas constantes e erros 500.
**Técnica 3 -- Nome:** Evitando uso de tags e códigos desnecessários
